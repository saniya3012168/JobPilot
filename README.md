# 🚀 JobPilot – Job Application Tracking System

JobPilot is a full-stack web application that helps users manage and track their job applications efficiently.  
It provides features like authentication, job tracking, resume management, interview preparation, and analytics.

---

## 🧠 Abstract
JobPilot centralizes the job search process by allowing users to add, update, and track job applications, upload resumes, prepare for interviews, and view progress analytics — all in one place.  
The application follows a REST API–based architecture with a modern React frontend and a Flask backend.

---

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript (ES6+)
- Vite
- React Router DOM
- Axios
- Tailwind CSS / CSS

### Backend
- Python
- Flask
- Flask-SQLAlchemy
- Flask-JWT-Extended
- Flask-CORS

### Database
- SQLite (development)

---

## ✨ Features
- User authentication using JWT
- Job application CRUD operations
- Application status tracking
- Resume upload & management
- Interview preparation module
- Profile management
- Analytics dashboard
- Secure REST APIs
